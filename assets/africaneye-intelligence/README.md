# AfricanEye Intelligence Frontend

This directory is reserved for the vendored, frontend-only AfricanEye Intelligence Map extracted from the AfrOsint application.

## Source protection

The `BlackSurvivalGear/AfrOsint` repository is a read-only source/reference repository for this integration. It must not be modified as part of AfricanEye development.

## Integration rules

- Frontend only.
- No Firebase authentication, Firestore, Storage, or AfrOsint backend services.
- No runtime dependency on the AfrOsint repository.
- All visible AfrOsint branding is replaced with AfricanEye branding.
- AfricanEye owns and serves the resulting frontend assets.
